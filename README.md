# Basic Rule-Based Chatbot using Python

## About the Project
This is a simple rule-based chatbot developed using Python.
It responds to specific user messages with predefined replies.

## Features
- Responds to hello with Hi!
- Responds to how are you with I'm fine, thanks!
- Responds to bye with Goodbye!
- Handles unknown messages
- Accepts uppercase and lowercase inputs

## Technologies Used
- Python
- While loop
- If-elif-else statements
- String methods

## How to Run
1. Install Python on your computer.
2. Download the chatbot.py file.
3. Open a terminal in the folder containing the file.
4. Run the following command:

   python chatbot.py

## Objective
The objective of this project is to understand the basic working of a rule-based chatbot using Python.
